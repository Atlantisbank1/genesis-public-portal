2. PHASE OBJECTIVE
============================================================

Phase 7.2 establishes invitation-gated Trust Club registration.

The approved registration flow is:

Invitation Request
-> Administrative Token Issuance
-> Invitation Redemption
-> Registration Admission
-> Better Auth Sign-Up

Registration admission is not authentication authority.

Better Auth remains the sole authority for:
- credential verification;
- user creation;
- account creation;
- session creation.

Trust Club registration admission:
- requires an already-consumed invitation;
- binds the invitation proof to normalized email;
- is time-bounded;
- does not establish Membership;
- does not grant Trust roles;
- does not authorize Trust actions.
